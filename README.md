# VYORA — Work Smarter. Move Faster.

VYORA is a modern SaaS project management and team productivity platform designed to help teams organize projects, manage tasks, collaborate effectively, and track progress from one unified workspace.

## Features

- **Modern Landing Page:** Clean, responsive interface with smooth navigation.
- **Interactive Dashboard:** Overview, My Tasks, Team Space, and Timeline tabs.
- **Project Management:** Create and add new projects dynamically.
- **Progress Tracking:** Visual progress bars and workspace statistics.
- **How It Works:** A simple three-step introduction to the platform.
- **Pricing Plans:** Essential and Growth plans with monthly/yearly selection.
- **Contact Form:** Form validation and submission success message.
- **Responsive Design:** Optimized for desktop, tablet, and mobile devices.

## Getting Started

### Prerequisites

- Node.js
- npm
- Visual Studio Code (recommended)

### Installation

1. Clone or download this repository.
2. Open the project folder in your terminal.
3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal.

## Design Direction

VYORA uses a refined visual identity built around deep pond green, verdigris, amethyst, gilded beige, and muted blue-grey tones. The interface combines expressive typography, spacious layouts, subtle animations, and clear visual hierarchy to create a polished productivity experience.

## Notes

VYORA is a frontend demonstration project. Project creation and form interactions are handled on the client side. No backend, database, authentication, or payment processing is connected.
